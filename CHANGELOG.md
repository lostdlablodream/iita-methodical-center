# История изменений

## Unreleased

### Добавлено

- Полный путь «каталог → слот → потребность → запись → отмена → повторная запись» в локальном и серверном режимах.
- 12 консультаций, 31 слот, поиск и фильтры по теме, институту и формату; единый seed с 20 институтами и 6 темами.
- Двухрежимный repository, один ключ `iita.consultations.state.v1`, Web Locks, идемпотентные создание и отмена.
- Python stdlib + SQLite REST API: транзакции, HMAC-SHA-256 владельца, аналитика и погодный proxy.
- Non-root Docker runtime с read-only файловой системой, volume и healthcheck.
- «Мои записи» с историей, доступным dialog отмены, повторным оформлением и экспортом `.ics`.
- Аналитика потребностей с фильтром темы, KPI, диаграммами, таблицей 20 институтов и CSV без сырых обращений.
- Open-Meteo: current и hourly прогноз, loading/result/error/retry.
- SUTD-inspired navy/cyan палитра и проверенные WCAG-контрасты.

### Проверено

- PR #1–#6 созданы, проверены вторым участником, исправлены авторами и слиты лидом.
- Node-сценарии: repository, фильтры, идемпотентность, конкуренция, отмена, race, CSV/ICS и погода.
- Firefox: полный локальный путь, реальный hourly прогноз, календарь, отмена и повторное оформление.
- Docker: health, реальный server adapter, race capacity=1, restart persistence и 18 демонстрационных записей для проверки аналитики.

### Осталось

- Завершить PR аналитики, опубликовать GitHub Pages и развернуть отдельный Docker-контур.
- Проверить опубликованный и серверный пути в Firefox, мобильную ширину, клавиатуру и ошибку внешнего API.
- Обновить README/ARCHITECTURE, добавить фактические PR-ссылки и использованные промпты.
