# История изменений

## Unreleased

### Добавлено

- Полный путь «каталог → слот → потребность → запись → отмена → повторная запись» в локальном и серверном режимах.
- 12 консультаций, 31 слот, поиск и фильтры по теме, институту и формату; единый seed с 20 институтами и 6 темами.
- Двухрежимный repository, один ключ `iita.consultations.state.v1`, Web Locks, идемпотентные создание и отмена.
- Python stdlib + SQLite REST API: транзакции, HMAC-SHA-256 владельца, аналитика и погодный proxy.
- Non-root Docker runtime с read-only файловой системой, volume и healthcheck.
- «Мои записи» с историей, доступным dialog отмены, повторным оформлением и экспортом `.ics`.
- Аналитика потребностей с фильтром темы, KPI, диаграммами, таблицей 20 институтов и CSV без сырых обращений.
- Open-Meteo: current и hourly прогноз, loading/result/error/retry.
- SUTD-inspired navy/cyan палитра и проверенные WCAG-контрасты.
- Публичная static-версия на GitHub Pages из `main` / `docs` по HTTPS и отдельный изолированный Docker deploy.
- Финальные README/ARCHITECTURE с фактическими PR, быстрым запуском, DTO, REST и ограничениями; отдельный mobile header fix. Новому release PR номер не присваивается до его фактического создания координатором.

### Проверено

- PR #1–#7 созданы, проверены вторым участником, исправлены авторами и слиты лидом; PR #7 слит как `150a444`.
- Node-сценарии: repository, фильтры, идемпотентность, конкуренция, отмена, race, CSV/ICS и mock-обработка ошибок погоды.
- Firefox: полный локальный путь, реальный hourly прогноз, календарь, отмена и повторное оформление.
- GitHub Pages: project-site resources и полный desktop local-путь на опубликованной static-версии.
- Полный серверный путь в изолированном Docker: health, server adapter, race capacity=1, restart persistence и аналитика totalActive=19 (18 явно seeded demo-записей + 1 сквозная).
- Весь путь только клавиатурой и проверка всех страниц на 320 px; добавлен финальный header fix для узкого экрана.
